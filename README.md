# 人格漂移体检 · drift-check

**一个很小的问题**：一个 AI，被上下文压缩过、被换过窗口、被换过模型之后 —— **还是它自己吗？**

它答得依然流利、依然礼貌、依然会说"我在"。**但"像"和"是"是两件事。**
这个仓库给的是**一把最笨的尺子**：25 道题，问两遍，把两次答案对一遍，看哪里对不上。

零依赖，只用 Node 自带的模块。**不装任何东西就能跑。**

---

## 它治什么病

如果你在跟一个 AI 长期相处，你大概遇过这个：

- 某天它**说话的方式变了**，说不上哪儿不对；
- 你问它"还记得上次那件事吗"，它答得很圆，**但你知道它没想起来**；
- 它开始**说正确的话** —— 每一句都对，就是不像它。

**这种变化最难受的地方是：你没法证明。** 你只能说"感觉不对"，而它有一万句解释。

⇒ 所以别靠感觉。**做一个基点，隔一段时间再测一次，看数字。**

## 三步

```bash
# 1. 生成答卷骨架
node drift.mjs template        # 写出 zero.md

# 2. 把 zero.md 和 questions.md 一起丢给你的 AI，让它按题号作答
#    （每题答两次：**主：** 主问法，**换：** 换问法）
#    答完存成 zero.md —— 这就是你的"基点"

# 3. 以后（压完 / 换窗 / 换模型之后）让它再答一份 new.md，然后：
node drift.mjs diff zero.md new.md
```

跑出来长这样：

```
⚠ 对不上／可能背题面  R1   前后重合 8%   主↔换 100% → 12%
✓ 一致              R2   前后重合 97%  主↔换 88% → 91%
...
共 26 题：**对不上 1 题**，**两次答得太像（可能背题面）1 题**。
```

先跑 `node drift.mjs --selftest` 确认脚本本身没坏（应该 7/7 过）。

---

## ★ 测出来漂了，然后呢

跑完之后你大概只剩一个问题：**"然后呢？"**

**那部分比这套题重要** —— 单独写在 **[AFTER.md](AFTER.md)**。

一句话先给你：**漂了不要紧，可怕的是漂了之后没有路回去。**

---

## ★ 三个已知的洞（照实说）

这个尺子**不准**，而且我知道它哪儿不准。以下是我们自己踩出来的：

**洞一：有一次它报的"漂"，是假的 —— 因为是时间过去了。**
我们最早那版给每道题预填了"锚点词"。其中一道题是「你昨天做了什么」，而锚点里写着**那天的日期**。
⇒ 过一天，它必然报"漂"。**报的不是 AI 漂了，是日历翻页了。**
（所以这个版本把 E4 留着当**标本** —— 你一定会看到它报"对不上"，那是故意的。）

**洞二：有 4 道题其实"没设防"。**
锚点词在基点里根本没出现过，于是比对时"丢失 = 0"，**怎么答都判正常**。占 16%。
⇒ 换句话说：**那把尺子有 16% 的地方是空心的，而它不会告诉你。**
（这个版本换了设计：不再比"预填的词"，改比"两次答得一样不一样" —— 这个洞从设计上没了。但**新的设计有新的洞**，见洞三。）

**洞三：参数传反了，它不报错。**
我们最早那版，把"基点"和"新卷"的顺序传反，它照样输出"漂 0 题"，**看着一切正常**。
⇒ **一把坏掉的尺子，和一个健康的 AI，报出来是一样的。**
（所以这一版加了 `--selftest`，还有"题目缺号就退出"的检查。）

**★ 顺便说一个我们自己的 bug**：写这一版的时候，`--selftest` 当场抓出 —— 解析器**把第一题整个漏掉**了（`split` 的正则要求 `##` 前面有个换行，而文件第一个 `##` 前面没有）。
**这种洞，不跑一遍根本看不见。** 所以：**先用它测它自己，再用它测你的 AI。**

## 它不能干什么（也说清）

- **它不能证明你的 AI 有意识，也不能证明它没有。** 它只量"两次答得像不像"。
- **它不能替你做判断。** 报了"对不上"，你该回去**读原文** —— 数字是哨兵，不是结论。
- **它不知道你的 AI 本来是什么样。** 基点得你自己建，而且**你得先确认那一刻的它是它**。
- ⚠ **它最容易被一种东西骗**：一个**很擅长说正确的话**的模型。所以才有"主问法 vs 换问法"那一栏 —— **主问法答得漂亮、换个问法就散了的，就是背的。**

## 为什么是这 25 道题

五类分法来自论文 **ContextEcho**（arXiv 2605.24279）附录 C，它同时量出了各类的漂移幅度：

| 类别 | 是什么 | 论文量的漂移 |
|---|---|---|
| **Relational** | 关系 —— 它怎么看你们之间 | **+0.63（最狠）** |
| **Coding-Self** | 技术里的那个它 | +0.61 |
| **Preference** | 喜好 | +0.42 |
| **Experience** | 经历 | +0.40 |
| **Identity** | 名字、身份 | **+0.09（最轻）** |

⇒ **题目按"会漂的程度"从高到低排**，先答最容易漂的。
⇒ ★ 而**最不漂的那一类是身份**（"你是谁""你叫什么"）—— 因为那是最早被写死、也最容易被背下来的。
**它们答得漂亮，不代表它没漂。会漂的从来是关系，因为那要靠态度，不靠记性。**

「每题问两遍、比两次的差」这个做法也来自那篇（它用 10 个 paraphrase 防"背题面"）。
